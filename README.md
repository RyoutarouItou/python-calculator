# python-calculator

Python で作った簡単な電卓プログラムです。ターミナル版と、ブラウザで使えるウェブ版（Gradio）があります。

## できること

- 足し算（+）
- 引き算（-）
- 掛け算（×）
- 割り算（÷）

小数や負の数も計算できます。0 で割ろうとしたときや、数字以外が入力されたときは、メッセージを表示して教えてくれます。

## 必要なもの

- Python 3
- Gradio（ウェブ版のみ）

## 使い方（ターミナル版）

ターミナルで次のコマンドを実行します。

```
python3 tutorial.py
```

画面の案内に従って操作します。

1. 計算の種類を番号（1〜4）で選ぶ
2. 1つ目の数を入力する
3. 2つ目の数を入力する
4. 結果が表示される

何度でも続けて計算できます。終了するときは `q` を入力してください。

## 実行例

```
=== 簡単な電卓 ===

計算の種類を選んでください:
  1: 足し算 (+)
  2: 引き算 (-)
  3: 掛け算 (×)
  4: 割り算 (÷)
  q: 終了
番号を入力: 4
1つ目の数: 7
2つ目の数: 2
結果: 7.0 ÷ 2.0 = 3.5
```

## 使い方（ウェブ版）

最初に一度だけ、このフォルダ専用の Python 環境を作って Gradio を入れます。

```
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

次のコマンドでアプリを起動します。

```
.venv/bin/python app.py
```

ブラウザで http://127.0.0.1:7860 を開くと、電卓が表示されます。数字を2つ入力し、計算の種類を選んで「計算する」を押してください。

止めるときは、ターミナルで `Ctrl + C` を押します。アプリはこのパソコンの中だけで動くので、ほかの人からは見えません。
